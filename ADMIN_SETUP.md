After you've created your admin account:

1. **Login as Admin**
2. **Go to Admin Panel** → **Users Management**
3. **Find the User** you want to promote
4. **Change Role** from "User" to "Admin"
5. **Save Changes**

## 🆘 Troubleshooting

### "I registered but don't see the Admin button"
- You might not be the first user
- Check if someone else already registered
- Login to admin panel and check the Users Management page
- Contact the first registered user to promote you to admin

### "I forgot my admin password"
- Use the "Forgot Password" feature (if enabled)
- Or reset it through Supabase dashboard:
  1. Go to Supabase Dashboard
  2. Navigate to Authentication → Users
  3. Find your user
  4. Reset password

### "I want to change who is admin"
- Login as current admin
- Go to Users Management
- Change roles as needed
- You can have multiple admins
